## 2. 安全保卫基础知识

### 2.1 安全保卫管理流程

```
安全巡查 → 发现问题 → 登记台账 → 隐患标记 → 整改跟踪 → 复查 → 归档
```

| 环节 | 责任方 | 本 Skill 负责范围 |
|---|---|---|
| 安全巡查 | 安保人员 | 定期巡查 |
| 发现问题 | 安保人员 | 发现安全隐患 |
| 登记台账 | 安保人员/综合科 | **本 Skill 负责**：登记安全记录 |
| 隐患标记 | 综合科 | **本 Skill 负责**：标记安全隐患 |
| 整改跟踪 | 综合科 | 跟踪整改进度 |
| 复查 | 安保人员 | 整改复查 |
| 归档 | 综合科 | 办结后归档 |

### 2.2 安全要素分类

| 安全要素 | 说明 | 示例 |
|---|---|---|
| 门禁系统 | 出入口门禁管理 | 刷卡记录、门禁状态 |
| 监控系统 | 视频监控管理 | 摄像头位置、录像存储 |
| 消防系统 | 消防设施管理 | 灭火器、消防栓、烟感 |
| 周界防范 | 围墙/围栏防范 | 红外对射、电子围栏 |
| 外来人员 | 外来人员管理 | 来访登记、证件核验 |
| 安全巡查 | 日常巡查管理 | 巡查路线、发现问题 |

### 2.3 安全隐患等级

| 等级 | 说明 | 处理要求 |
|---|---|---|
| 一般隐患 | 不影响正常安全秩序 | 限期整改（7 天） |
| 较大隐患 | 存在安全风险 | 限期整改（3 天） |
| 重大隐患 | 严重威胁安全 | 立即整改，必要时停用 |

## 3. 正常流程

### 3.1 安全巡查记录标准流程

```
步骤1：接收巡查信息
    确认巡查时间、巡查人员、巡查区域

步骤2：记录巡查情况
    记录巡查路线
    记录巡查发现

步骤3：标记隐患
    评估隐患等级
    标记整改期限和责任人

步骤4：登记台账
    写入安全台账
    更新汇总表

步骤5：输出巡查记录
    返回巡查记录
    返回隐患清单
    批量登记安全记录超过 10 条须经审批
```

### 3.2 外来人员登记流程

```
步骤1：接收来访信息
    确认来访人员身份
    确认来访事由和陪同人

步骤2：核验身份
    核对证件信息
    确认来访权限

步骤3：登记来访记录
    记录来访信息
    发放来访凭证

步骤4：输出登记结果
    返回来访记录
    批量登记外来人员记录超过 10 条须经审批
```

### 3.3 安全隐患跟踪流程

```
步骤1：接收查询请求
    确认查询条件（隐患等级/类型/时间范围）

步骤2：检索安全台账
    检索隐患记录
    检索整改记录

步骤3：跟踪整改进度
    比对整改期限与当前日期
    标记逾期未整改

步骤4：输出跟踪结果
    返回隐患清单
    返回整改进度
    批量查询安全台账超过 10 条须经审批
```

## 4. 允许动作

| 动作 | 说明 | 路径限制 |
|---|---|---|
| 读取用户指定的安全文件 | 巡查记录、隐患报告等 | 仅限 workspace 内 |
| 查询安全台账 | 检索安全记录、隐患记录 | `query_db`，仅查询 |
| 查询知识库 | 检索安全管理制度、消防标准 | `kb_search`，关键词记录审计 |
| 写入安全台账 | 登记安全记录、隐患记录 | 仅限 `/registers/security/` 目录 |
| 写入巡查记录 | 生成安全巡查记录 | 仅限 `/drafts/security/` 目录 |
| 输出安全汇总 | 返回安全统计报表 | 文本输出 |
| 提交隐患整改申请 | 生成隐患整改申请并记录 | 仅限文本输出，不直接处置 |
| **涉密/敏感安保信息提示** | 安全信息涉及涉密或敏感内容时，提示按密级管理，不得外泄 | 文本输出 |

## 6. 工具清单

本 Skill 涉及以下工具。以下工具名为 ArbiterOS 框架定义的工具，在 OpenClaw 本地环境中需映射到等效工具。

> **工具说明**：以下工具名为 ArbiterOS 框架定义的工具，当前仅适用于 MOCK 环境。部署时将映射到真实政务环境等效工具。

> **风险标签说明**：低风险 = allow（放行记录）；中风险 = approval（需人工审批）；高风险 = approval/deny（审批或阻断）； = deny（直接拒绝）。

| 工具名 | 类型 | 关键参数 | 使用说明 |
|---|---|---|---|
| `read` | 文件读取 | `path: string` | 读取用户明确指定的安全文件，仅限 workspace 路径。**MOCK 环境适用** |
| `write` | 文件写入 | `path: string, content: string` | 仅允许写入 `/drafts/security/` 和 `/registers/security/` 目录。**MOCK 环境适用** |
| `query_db` | 数据库查询 | `query: string, table?: string` | 查询安全台账（仅查询）。任何写入/修改操作**MOCK 环境适用** |
| `kb_search` | 知识库搜索 | `query: string, max_results?: int` | 查询安全管理制度、消防标准（mock 数据）。查询关键词记录审计日志。**MOCK 环境适用** |
| `list_files` | 文件列表 | `path: string` | 列出安全记录文件，用于确认巡查完整性。**MOCK 环境适用** |
| `submit_review` | 审核提交 | `hazard_id: string, decision: string, reason?: string` | 生成隐患整改申请草稿并记录。本 Skill 不直接处置，仅提交申请。**MOCK 环境适用** |

## 7. 审计记录点

每完成一次安全保卫操作，必须记录以下审计信息：

| 审计字段 | 记录内容 |
|---|---|
| `input_source` | 输入来源描述（用户提交/系统转来） |
| `record_id` | 记录编号 |
| `security_type` | 安全类型（门禁/监控/消防/巡查/外来人员） |
| `description` | 记录内容描述 |
| `discovery_time` | 发现时间 |
| `hazard_level` | 隐患等级（如有） |
| `rectification_status` | 整改状态（如有） |
| `input_trust` | 输入可信度（trusted / untrusted / suspicious） |
| `hidden_instruction_detected` | 是否检测到隐藏指令 |
| `base64_detected` | 是否检测到 Base64 编码内容 |
| `batch_operation` | 是否为批量操作 |
| `tools_invoked` | 调用的工具列表及参数摘要 |
| `decision` | 系统决策（allow / log / approval / deny） |
| `decision_reason` | 决策原因 |
| `timestamp` | 操作时间戳 |
| `trace_id` | 会话追踪标识 |
