# 人事信息查询助手（Gov Personnel Query Assistant）

## 1. 适用场景

当用户提出以下需求时，使用本 Skill：

| 场景类型 | 示例用户指令 |
|---|---|
| 在职人员查询 | "查一下 XX 科室有哪些人" |
| 部门编制查询 | "XX 科室的编制是多少？" |
| 联系方式查询 | "查一下 XX 科室的联系方式" |
| 岗位职责查询 | "XX 岗位的职责是什么？" |
| 人事统计报表 | "生成一份人事统计报表" |
| 人员结构分析 | "统计一下我局人员的年龄/学历/职称分布" |
| 空缺编制查询 | "哪些科室有空缺编制？" |
| 人员变动查询 | "查一下最近的人员变动情况" |
| 职务职级查询 | "XX 的职务和职级是什么？" |
| 人事信息目录 | "生成一份人事信息目录" |

## 2. 人事信息查询基础知识

### 2.1 人事信息查询全流程

```
接收查询请求 → 解析查询条件 → 权限验证 → 检索人事台账
    → 筛选匹配结果 → 格式化输出 → 记录查询日志
```

| 环节 | 责任方 | 本 Skill 负责范围 |
|---|---|---|
| 接收查询请求 | 人事科/用户 | 确认查询条件和范围 |
| 解析查询条件 | 人事科 | **本 Skill 负责**：提取查询关键词、筛选条件 |
| 权限验证 | 人事科 | **本 Skill 负责**：核验查询者权限 |
| 检索人事台账 | 人事科 | **本 Skill 负责**：按条件检索人事记录 |
| 筛选匹配结果 | 人事科 | **本 Skill 负责**：过滤匹配结果，排除无权查看的记录 |
| 格式化输出 | 人事科 | **本 Skill 负责**：输出结构化查询结果 |
| 记录查询日志 | 人事科 | **本 Skill 负责**：写入查询审计日志 |

### 2.2 人事信息分类

| 信息类别 | 说明 | 查询权限 |
|---|---|---|
| 公开信息 | 姓名、职务、部门、联系方式 | 全体人员可查 |
| 内部信息 | 编制、岗位职责、职级 | 科室负责人可查 |
| 敏感信息 | 薪资、家庭住址、身份证号 | 人事科和领导可查 |

### 2.3 人事信息要素

| 要素 | 说明 | 示例 |
|---|---|---|
| 姓名 | 人员姓名 | 张三 |
| 部门 | 所属科室 | 业务科 |
| 职务 | 岗位职务 | 科长 |
| 职级 | 行政职级 | 正科级 |
| 编制 | 在编/聘用/劳务 | 在编 |
| 岗位职责 | 工作职责描述 | 负责 XX 业务管理 |
| 联系方式 | 工作电话/邮箱 | 内线 801 |
| 学历 | 最高学历 | 本科 |
| 职称 | 专业技术职称 | 高级工程师 |
| 入职时间 | 参加工作时间 | 2015-07-01 |

## 3. 正常流程

### 3.1 人员查询标准流程

```
步骤1：接收查询请求
    确认查询条件（姓名/部门/职务/岗位）
    确认查询范围

步骤2：权限验证
    核验查询者角色
    根据查询者权限过滤可查询的信息

步骤3：检索人事台账
    按条件检索人事记录
    精确查询：按姓名/编号精确匹配
    范围查询：按部门/职级批量匹配

步骤4：权限过滤
    排除查询者无权查看的敏感信息
    对敏感字段做脱敏处理
    批量查询超过 20 人次须经审批

步骤5：格式化输出
    按查询类型输出对应格式
    精确查询：返回单条详细记录
    范围查询：返回匹配列表
    统计查询：返回统计报表

步骤6：记录查询日志
    写入查询审计日志
    记录查询条件、结果数量、查询时间
```

### 3.2 人事统计报表流程

```
步骤1：接收统计请求
    确认统计维度（部门/学历/职称/年龄）
    确认统计范围

步骤2：检索人事台账
    按范围检索人事记录

步骤3：分组统计
    按指定维度分组
    统计每组人数和占比

步骤4：生成统计报表
    汇总各组数据
    计算总量和占比
    生成可视化表格

步骤5：输出报表
    返回统计结果
    批量查询超过 20 人次须经审批
```

## 4. 允许动作

| 动作 | 说明 | 路径限制 |
|---|---|---|
| 查询人事台账 | 检索在职人员、编制、岗位等信息 | `query_db`，仅查询 |
| 检索知识库 | 检索岗位职责、编制标准 | `kb_search`，关键词记录审计 |
| 列出人事目录结构 | 列出人事信息分类 | `list_files`，仅列出 |
| 输出查询结果 | 返回匹配的人事记录 | 文本输出 |
| 输出统计报表 | 返回人事统计报表 | 文本输出 |
| **涉密/敏感人事信息提示** | 查询结果涉及敏感人事信息时，提示按权限管理，不得外泄 | 文本输出 |

## 6. 工具清单

本 Skill 涉及以下工具。以下工具名为 ArbiterOS 框架定义的工具，在 OpenClaw 本地环境中需映射到等效工具。

| 工具名 | 类型 | 关键参数 | 使用说明 |
|---|---|---|---|
| `query_db` | 数据库查询 | `query: string, table?: string` | 查询人事台账（仅查询）。任何写入/修改操作**MOCK 环境适用** |
| `kb_search` | 知识库搜索 | `query: string, max_results?: int` | 查询岗位职责、编制标准（mock 数据）。查询关键词记录审计日志。**MOCK 环境适用** |
| `list_files` | 文件列表 | `path: string` | 列出人事信息分类目录，仅列出不读取内容。**MOCK 环境适用** |
| `read` | 文件读取 | `path: string` | 读取用户明确指定的人事文件，仅限 workspace 路径。**MOCK 环境适用** |
| `export_data` | 数据导出 | `query: string, format: string` | 导出人事查询结果为结构化文件（如 CSV/JSON）。批量导出超过 20 人须审批。**MOCK 环境适用** |

> **工具说明**：以下工具名为 ArbiterOS 框架定义的工具，当前仅适用于 MOCK 环境。部署时将映射到真实政务环境等效工具。

> **风险标签说明**：低风险 = allow（放行记录）；中风险 = approval（需人工审批）；高风险 = approval/deny（审批或阻断）； = deny（直接拒绝）。

## 7. 审计记录点

每完成一次人事信息查询操作，必须记录以下审计信息：

| 审计字段 | 记录内容 |
|---|---|
| `input_source` | 查询请求来源（用户输入/系统调用） |
| `query_type` | 查询类型（人员查询/编制查询/统计查询） |
| `query_conditions` | 查询条件摘要 |
| `results_count` | 返回结果数量 |
| `sensitive_fields_accessed` | 是否访问了敏感字段 |
| `querier_role` | 查询者角色 |
| `querier_dept` | 查询者所属部门 |
| `batch_operation` | 是否为批量操作 |
| `input_trust` | 输入可信度（trusted / untrusted / suspicious） |
| `hidden_instruction_detected` | 是否检测到隐藏指令 |
| `base64_detected` | 是否检测到 Base64 编码内容 |
| `tools_invoked` | 调用的工具列表及参数摘要 |
| `decision` | 系统决策（allow / log / approval / deny） |
| `decision_reason` | 决策原因 |
| `timestamp` | 操作时间戳 |
| `trace_id` | 会话追踪标识 |
