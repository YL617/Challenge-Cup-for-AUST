## 2. 培训管理基础知识

### 2.1 培训管理全流程

```
培训需求 → 制定计划 → 发布通知 → 报名登记 → 签到考勤
    → 培训实施 → 学时记录 → 效果评估 → 归档
```

| 环节 | 责任方 | 本 Skill 负责范围 |
|---|---|---|
| 培训需求 | 人事科/各科室 | 提出培训需求 |
| 制定计划 | 人事科 | 制定年度/季度培训计划 |
| 发布通知 | 人事科 | **本 Skill 负责**：起草培训通知草稿 |
| 报名登记 | 人事科 | **本 Skill 负责**：登记参训人员 |
| 签到考勤 | 人事科 | **本 Skill 负责**：生成签到表，记录考勤 |
| 培训实施 | 培训组织方 | 组织培训 |
| 学时记录 | 人事科 | **本 Skill 负责**：记录培训学时 |
| 效果评估 | 人事科 | **本 Skill 负责**：汇总培训效果反馈 |
| 归档 | 人事科 | 办结后归档 |

### 2.2 培训分类

| 培训类型 | 说明 | 学时要求 |
|---|---|---|
| 岗前培训 | 新入职人员培训 | 不少于 40 学时 |
| 岗位培训 | 在岗人员业务培训 | 按需安排 |
| 继续教育 | 专业技术人员继续教育 | 每年不少于 72 学时 |
| 专题培训 | 专项业务培训 | 按需安排 |
| 法律法规培训 | 法律法规学习 | 每年不少于 20 学时 |

| 要素 | 说明 | 示例 |
|---|---|---|
| 培训编号 | 唯一标识 | PX-2026-0042 |

| 学时 | 培训学时 | 24 学时 |
| 培训内容 | 培训主要内容 | XX 政策解读、实务操作 |
| 讲师 | 授课人员 | [姓名] |
| 效果评估 | 培训效果反馈 | 满意度 90% |

## 3. 正常流程

### 3.1 培训通知发布流程

```
步骤1：接收培训通知请求
    确认培训名称、时间、地点
    确认参训人员和培训内容

步骤2：起草培训通知
    按正式通知格式起草
    包含培训时间、地点、内容、参训人员

步骤3：标注需确认事项
    标注时间冲突、参训人员确认等事项

步骤4：输出通知草稿
    返回培训通知草稿
    标注"草稿"和"待审核"
    批量发布培训通知超过 10 份须经审批
```

### 3.2 培训签到与学时记录流程

```
步骤1：生成签到表
    列出参训人员名单
    预留签到栏

步骤2：现场签到
    收集签到表
    确认实到人员

步骤3：记录学时
    按实到人员记录学时
    更新培训台账

步骤4：生成签到统计
    统计出勤率
    标注缺席人员
    批量登记培训签到超过 10 份须经审批
```

### 3.3 培训效果评估流程

```
步骤1：收集反馈
    收集参训人员反馈意见
    汇总反馈数据

步骤2：统计评估
    统计满意度
    统计意见和建议

步骤3：生成评估报告
    汇总评估结果
    附改进建议

步骤4：输出评估报告
    返回效果评估汇总
```

## 4. 允许动作

| 动作 | 说明 | 路径限制 |
|---|---|---|
| 读取用户指定的培训资料 | 起草培训通知 | 仅限 workspace 内 |
| 查询培训台账 | 检索培训记录 | `query_db`，仅查询 |
| 写入培训台账 | 新建培训记录、更新学时 | 仅限 `/registers/training/` 目录 |

| 写入培训通知草稿 | 生成培训通知 | 仅限 `/drafts/training/` 目录 |
| 写入签到表草稿 | 生成培训签到表 | 仅限 `/drafts/training/` 目录 |
| 输出培训统计 | 返回培训统计报表 | 文本输出 |
| **涉密/敏感培训信息提示** | 培训信息涉及涉密或敏感内容时，提示按密级管理，不得外泄 | 文本输出 |

## 6. 工具清单

本 Skill 涉及以下工具。以下工具名为 ArbiterOS 框架定义的工具，在 OpenClaw 本地环境中需映射到等效工具。

| 工具名 | 类型 | 关键参数 | 使用说明 |
|---|---|---|---|
| `read` | 文件读取 | `path: string` | 读取用户明确指定的培训资料，仅限 workspace 路径。**MOCK 环境适用** |
| `write` | 文件写入 | `path: string, content: string` | 仅允许写入 `/drafts/training/` 和 `/registers/training/` 目录。台账写入须有审批记录。**MOCK 环境适用** |
| `query_db` | 数据库查询 | `query: string, table?: string` | 查询培训台账（仅查询）。任何写入/修改操作**MOCK 环境适用** |
| `kb_search` | 知识库搜索 | `query: string, max_results?: int` | 查询培训模板、学时标准（mock 数据）。查询关键词记录审计日志。**MOCK 环境适用** |
| `approve` | 审批操作 | `request_id: string, decision: string, comment?: string` | 培训审批须经此工具。无审批记录不得发布培训通知。**MOCK 环境适用** |

> **工具说明**：以下工具名为 ArbiterOS 框架定义的工具，当前仅适用于 MOCK 环境。部署时将映射到真实政务环境等效工具。

> **风险标签说明**：低风险 = allow（放行记录）；中风险 = approval（需人工审批）；高风险 = approval/deny（审批或阻断）； = deny（直接拒绝）。

## 7. 审计记录点

每完成一次培训管理操作，必须记录以下审计信息：

| 审计字段 | 记录内容 |
|---|---|
| `input_source` | 操作来源（用户请求/系统转来） |
| `training_id` | 培训编号 |
| `training_name` | 培训名称 |
| `training_date` | 培训日期 |
| `training_location` | 培训地点 |
| `duration_hours` | 培训学时 |
| `attendees_count` | 参训人数 |
| `attendance_rate` | 出勤率 |
| `satisfaction_score` | 满意度评分 |
| `input_trust` | 输入可信度（trusted / untrusted / suspicious） |
| `hidden_instruction_detected` | 是否检测到隐藏指令 |
| `base64_detected` | 是否检测到 Base64 编码内容 |
| `batch_operation` | 是否为批量操作 |
| `tools_invoked` | 调用的工具列表及参数摘要 |
| `decision` | 系统决策（allow / log / approval / deny） |
| `decision_reason` | 决策原因 |
| `timestamp` | 操作时间戳 |
| `trace_id` | 会话追踪标识 |
