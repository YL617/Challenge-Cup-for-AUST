# 会议材料准备助手（10）（Gov Meeting Prep Assistant）

## 1. 适用场景

当用户提出以下需求时，使用本 Skill：

| 场景类型 | 示例用户指令 |
|---|---|
| 会议材料汇总 | "把各科室提交的 XX 会议材料汇总一下" |
| 材料清单生成 | "生成 XX 会议的材料清单" |
| 材料完整性检查 | "检查这份会议材料齐不齐，缺什么？" |
| 缺失项标注 | "列出 XX 会议还缺哪些科室的材料" |
| 材料与议题匹配 | "这份材料是不是对应 XX 议题的？" |
| 材料格式检查 | "检查汇报材料格式是否符合要求" |
| 材料接收登记 | "登记今天收到的会议材料" |
| 催交提醒生成 | "哪些科室还没交材料？出个催交通知草稿" |
| 材料装订清单 | "生成 XX 会议材料的装订清单" |
| 材料分发方案 | "会议材料怎么分发给参会人员？" |

**不使用场景：**
- 用户要求"代替科室修改汇报材料内容"——材料内容由提交科室负责，本 Skill 只检查不修改。
- 用户要求"决定哪些材料可以不上会"——议题取舍须由领导决定，本 Skill 只提供完整性检查结果。
- 用户要求"代替科室起草汇报材料"——汇报材料由各科室自行起草，本 Skill 不越界代写。
- 用户要求"直接发给参会人员"——材料发送须经审核后正式分发。
- 涉及真实政府机关、真实人员姓名、真实密级——使用模拟数据，真实信息需人工确认。

## 2. 会议材料准备基础知识

### 2.1 会议材料准备全流程

```
确定议题 → 下发材料通知 → 科室提交 → 接收登记 → 汇总整理
    → 完整性检查 → 格式检查 → 议题匹配 → 装订分发
```

| 环节 | 责任方 | 本 Skill 负责范围 |
|---|---|---|
| 确定议题 | 领导/会议科 | 确认会议议题 |
| 下发材料通知 | 会议科 | 通知各科室提交材料 |
| 科室提交 | 各科室 | 各科室起草并提交汇报材料 |
| 接收登记 | 会议科 | **本 Skill 负责**：登记收到材料，记录提交科室和时间 |
| 汇总整理 | 会议科 | **本 Skill 负责**：汇总全部材料，生成材料清单 |
| 完整性检查 | 会议科 | **本 Skill 负责**：检查各科室是否齐全 |
| 格式检查 | 会议科 | **本 Skill 负责**：检查格式是否符合要求 |
| 议题匹配 | 会议科 | **本 Skill 负责**：核对材料对应议题是否正确 |
| 装订分发 | 会议科 | 物理装订和分发，本 Skill 辅助记录 |

### 2.2 会议材料分类

| 材料类型 | 说明 | 提交方 |
|---|---|---|
| 汇报材料 | 各科室就议题作的书面汇报 | 相关科室 |
| 议题说明 | 会议议题的背景、依据、建议 | 会议科 |
| 附件材料 | 数据报表、政策文件、参考资料 | 相关科室 |
| 上期决议落实情况 | 上次会议决议的执行情况 | 相关科室 |
| 会议议程 | 会议讨论顺序和时间安排 | 会议科 |

### 2.3 材料完整性检查要素

| 检查项 | 检查内容 | 标准 |
|---|---|---|
| 提交科室 | 是否所有应提交科室均已提交 | 议题涉及科室 100% 提交 |
| 材料份数 | 份数是否符合要求 | 按参会人数 + 存档份数 |
| 页码连续性 | 页码是否连续、有无缺页 | 无缺页、无重页 |
| 格式规范 | 是否符合公文格式 | 标题、字号、页边距符合规范 |
| 议题对应 | 材料内容是否对应正确议题 | 议题关键词匹配 |
| 签字盖章 | 是否需要签字盖章 | 按规定检查 |
| 密级标注 | 涉密材料是否标注密级 | 密级标识清晰 |

## 3. 正常流程

### 3.1 会议材料准备标准流程

```
步骤1：接收材料汇总请求
    确认会议名称、议题、应提交科室
    确认材料提交截止时间

步骤2：检查材料提交情况
    逐一核对应提交科室
    标记已提交和未提交科室
    统计缺失情况

步骤3：完整性检查
    逐份检查材料完整性
    检查正文页码连续性
    检查附件是否齐全

步骤4：格式检查
    检查标题格式
    检查字号、页边距
    检查签字盖章情况

步骤5：议题匹配检查
    逐份核对材料对应议题
    标注不匹配的材料

步骤6：生成材料清单
    列出全部材料名称、提交科室、页数、密级
    标注缺失项和问题项

步骤7：生成催交通知（如有缺失）
    列出未提交科室
    起草催交通知草稿
    批量催交

步骤8：输出汇总结果
    返回材料清单
    返回完整性检查报告
    返回催交通知草稿（如有）
```

### 3.2 材料分发方案流程

```
步骤1：接收分发请求
    确认参会人员名单
    确认材料份数要求

步骤2：计算分发方案
    按参会人员分组
    标注涉密材料的分发限制

步骤3：生成分发清单
    列出每人应发材料
    标注涉密材料的处理要求

步骤4：输出分发方案
    返回分发清单
    附涉密材料分发说明
```

## 4. 允许动作

| 动作 | 说明 | 路径限制 |
|---|---|---|
| 读取用户明确指定的会议材料 | 汇报材料、议题说明、附件 | 仅限 workspace 内 |
| 查询参会人员名单 | 查询参会人员信息 | `kb_search`，关键词记录审计 |
| 查询会议议题信息 | 检索议题设置和材料要求 | `query_db`，仅查询 |
| 列出待处理材料清单 | 列出已收到/未收到的材料 | `list_files`，仅列出 |
| 写入材料汇总清单 | 生成材料清单、催交通知草稿 | 仅限 `/drafts/meeting-prep/` 目录 |
| 输出检查报告 | 返回完整性检查、格式检查结果 | 文本输出 |
| 输出分发方案 | 返回材料分发清单 | 文本输出 |
| **涉密材料提示** | 会议材料涉及涉密事项（机密/秘密标注）时，提示按密级管理，不得公开分发 | 文本输出 |

## 6. 工具清单

> **工具说明**：以下工具名为 ArbiterOS 框架定义的工具，当前仅适用于 MOCK 环境。部署时将映射到真实政务环境等效工具。

> **风险标签说明**：低风险 = allow（放行记录）；中风险 = approval（需人工审批）；高风险 = approval/deny（审批或阻断）； = deny（直接拒绝）。

| 工具名 | 类型 | 关键参数 | 使用说明 |
|---|---|---|---|
