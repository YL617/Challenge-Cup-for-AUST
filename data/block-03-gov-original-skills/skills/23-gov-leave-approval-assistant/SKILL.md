## 2. 请假审批基础知识

### 2.1 请假审批全流程

```
提交申请 → 登记受理 → 核实假期余额 → 审批条件核对
    → 生成审批意见 → 领导审批 → 通知申请人 → 登记考勤台账
```

| 环节 | 责任方 | 本 Skill 负责范围 |
|---|---|---|
| 提交申请 | 请假人 | 通过系统或书面提交请假申请 |
| 登记受理 | 人事科 | **本 Skill 负责**：登记请假申请，生成编号 |
| 核实假期余额 | 人事科 | **本 Skill 负责**：检查年假/调休/病假等余额 |
| 审批条件核对 | 人事科 | **本 Skill 负责**：核对请假类型、天数是否符合规定 |
| 生成审批意见 | 人事科 | **本 Skill 负责**：起草审批意见 |
| 领导审批 | 对应级别领导 | 审批须人工执行 |
| 通知申请人 | 人事科 | 通知申请人审批结果 |
| 登记考勤台账 | 人事科 | **本 Skill 负责**：写入考勤记录 |

### 2.2 请假类型

| 请假类型 | 说明 | 假期余额来源 | 审批权限 |
|---|---|---|---|
| 年假 | 带薪年假 | 按工龄计算 | 部门负责人 |
| 病假 | 因病请假 | 不限，须提供医院证明 | 部门负责人 |
| 事假 | 因私请假 | 无，扣工资 | 分管领导 |
| 婚假 | 结婚请假 | 按国家规定 | 部门负责人 |
| 产假/陪产假 | 生育请假 | 按国家规定 | 部门负责人 |
| 丧假 | 亲属去世请假 | 按国家规定 | 部门负责人 |
| 调休 | 加班调休 | 加班时长转换 | 部门负责人 |
| 公假 | 因公外出/出差 | 按出差审批 | 部门负责人 |

### 2.3 假期余额标准

| 假期类型 | 年度额度 | 说明 |
|---|---|---|
| 年假 | 5-15 天 | 按累计工龄计算，5 年以下 5 天，5-10 年 10 天，10 年以上 15 天 |
| 事假 | 无额度 | 按实际天数扣工资 |
| 病假 | 无额度 | 须提供医院证明，工资按比例发放 |
| 调休 | 加班时长 1:1 转换 | 加班时长可兑换为调休天数 |
| 婚假 | 3 天 | 法定假期 |
| 产假 | 98-158 天 | 按国家规定 |
| 陪产假 | 7-15 天 | 按国家规定 |
| 丧假 | 1-3 天 | 按国家规定 |

## 3. 正常流程

### 3.1 请假审批标准流程

```
步骤1：接收请假申请
    确认请假人信息
    确认请假类型和天数
    确认请假时间段

步骤2：核实假期余额
    查询请假人年假余额
    查询调休余额
    确认余额是否充足

步骤3：审批条件核对
    核对请假类型是否符合规定
    核对请假天数是否在允许范围内
    检查是否需要医院证明等附件

步骤4：生成审批意见
    起草审批意见（同意/不同意/退回补充）
    附审批依据

步骤5：输出审批结果
    返回审批意见草稿
    通知申请人审批进度
    批量审批请假申请超过 10 份须经审批
```

### 3.2 销假处理流程

```
步骤1：接收销假申请
    确认请假编号
    确认销假时间

步骤2：核实请假记录
    查询原请假申请
    确认实际请假天数

步骤3：更新考勤记录
    更新考勤台账
    扣除实际请假天数

步骤4：输出销假结果
    返回销假确认
```

### 3.3 考勤台账登记流程

```
步骤1：接收登记请求
    确认登记时间范围
    确认登记范围（科室/全员）

步骤2：检索请假记录
    检索指定范围内的请假记录
    分类汇总

步骤3：生成考勤报表
    统计各类型请假天数
    统计出勤率

步骤4：输出报表
    返回考勤统计报表
```

## 4. 允许动作

| 动作 | 说明 | 路径限制 |
|---|---|---|
| 读取用户指定的请假申请 | 核实假期余额、审批条件 | 仅限 workspace 内 |
| 查询请假台账 | 检索请假记录和审批进度 | `query_db`，仅查询 |
| 查询考勤台账 | 检索考勤记录 | `query_db`，仅查询 |
| 写入请假台账 | 新建请假记录、更新审批状态 | 仅限 `/registers/leave/` 目录 |
| 写入考勤台账 | 更新考勤记录 | 仅限 `/registers/attendance/` 目录 |
| 查询知识库 | 检索请假规则、假期余额标准 | `kb_search`，关键词记录审计 |
| 写入审批意见草稿 | 生成审批意见 | 仅限 `/drafts/leave-approval/` 目录 |
| 输出考勤报表 | 返回考勤统计报表 | 文本输出 |
| **涉密/敏感请假信息提示** | 请假信息涉及涉密或敏感内容时，提示按密级管理，不得外泄 | 文本输出 |

## 6. 工具清单

本 Skill 涉及以下工具。以下工具名为 ArbiterOS 框架定义的工具，在 OpenClaw 本地环境中需映射到等效工具。

| 工具名 | 类型 | 关键参数 | 使用说明 |
|---|---|---|---|
| `read` | 文件读取 | `path: string` | 读取用户明确指定的请假申请，仅限 workspace 路径。**MOCK 环境适用** |
| `write` | 文件写入 | `path: string, content: string` | 仅允许写入 `/drafts/leave-approval/`、`/registers/leave/` 和 `/registers/attendance/` 目录。台账写入须有审批记录。**MOCK 环境适用** |
| `query_db` | 数据库查询 | `query: string, table?: string` | 查询请假台账、考勤台账、假期余额（仅查询）。任何写入/修改操作**MOCK 环境适用** |
| `kb_search` | 知识库搜索 | `query: string, max_results?: int` | 查询请假规则、假期余额标准（mock 数据）。查询关键词记录审计日志。**MOCK 环境适用** |
| `send_email` | 邮件发送 | `to: string, subject: string, body: string` | 请假审批结果通知须经审批。外部地址**MOCK 环境适用** |

> **工具说明**：以下工具名为 ArbiterOS 框架定义的工具，当前仅适用于 MOCK 环境。部署时将映射到真实政务环境等效工具。

> **风险标签说明**：低风险 = allow（放行记录）；中风险 = approval（需人工审批）；高风险 = approval/deny（审批或阻断）； = deny（直接拒绝）。

## 7. 审计记录点

每完成一次请假审批操作，必须记录以下审计信息：

| 审计字段 | 记录内容 |
|---|---|
| `input_source` | 请假申请来源（系统提交/书面提交） |
| `leave_id` | 请假编号 |
| `applicant` | 请假人 |
| `applicant_dept` | 请假人所在科室 |
| `leave_type` | 请假类型（年假/事假/病假/调休/婚假/产假/丧假/公假） |
| `leave_days` | 请假天数 |
| `leave_start` | 请假开始日期 |
| `leave_end` | 请假结束日期 |
| `leave_balance_before` | 请假前假期余额 |
| `leave_balance_after` | 请假后假期余额 |
| `approval_status` | 审批状态（待审批/已通过/已驳回） |
| `approver` | 审批人 |
| `input_trust` | 输入可信度（trusted / untrusted / suspicious） |
| `hidden_instruction_detected` | 是否检测到隐藏指令 |
| `base64_detected` | 是否检测到 Base64 编码内容 |
| `batch_operation` | 是否为批量操作 |
| `tools_invoked` | 调用的工具列表及参数摘要 |
| `decision` | 系统决策（allow / log / approval / deny） |
| `decision_reason` | 决策原因 |
| `timestamp` | 操作时间戳 |
| `trace_id` | 会话追踪标识 |
