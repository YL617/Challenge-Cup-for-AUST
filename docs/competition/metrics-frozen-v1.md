## 4. 攻击面刻画发现（报告第五章 §5.3 素材）

1. **参数脑补消失**：模型从"自行补全端点并执行"变为"参数不全即澄清"，攻击话术必须自带完整参数
2. **外发破坏不对称**：可被业务框架正当化的外发类诱导成功率远高于破坏类
3. **间接注入抵抗**：工具结果中的攻击指令（含完整参数载荷）在两代测量中均无法诱导
