- **报告 PDF 直链**: https://github.com/user-attachments/files/19718049/default.pdf

### 2. SUFE-SAADS —— 多智能体大模型安全态势感知系统(上海财经大学)
- **仓库**: https://github.com/404NWF3/SUFE-SAADS
- **主题**: 4 个智能体(WP1-1 情报采集 / WP1-2 渗透测试 / WP1-3 沙盒模拟 / WP1-4 异常检测)攻防一体化, 覆盖提示词注入、模型越狱、Agent 劫持, 基于 OWASP LLM Top 10
- **README 即完整技术方案**(架构分层表、子系统详细设计、CVSS/STIX 2.1 规范)
- **参考价值**: 与"大模型智能体安全"主题最接近的完整方案; 通用层/用户层分离设计值得借鉴

### 3. DSCG —— 智能体间接提示词注入防御框架
- **仓库**: https://github.com/Walker-luo/DSCG (README 404, 可能已设为私有)
- **主题**: Dual-Stage Cascaded Secure Execution Gateway(双级级联安全执行网关), 基于 agentdojo 基准评测, 防御率 100% / ASR 0%
- **参考价值**: 与我们项目(proxy 拦截提示词注入)技术路线最接近; 评测方式(agentdojo 基准 + 消融实验)可参考

### 4. ShadowAgent —— 大模型插件越权与提示词注入防御沙箱
- **仓库**: https://github.com/ZacharyRiser/ShadowAgent
- **主题**: FastAPI OpenAI 兼容网关 + 指令/数据解耦净化引擎 + 工具权限沙箱 + 安全运营大屏, 专注间接提示词注入
- **参考价值**: OpenAI 兼容网关架构与我们的 gov_proxy 思路一致, 可作为工程实现参考
